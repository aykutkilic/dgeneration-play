# D/Generation — a three.js remake

Play at https://aykutkilic.github.io/dgeneration-play/

A browser remake of *D/Generation* (Robert Cook, Mindscape 1991). Ten floors of the Genoq Biolabs tower, escaped bioweapons, and a package for Dr. Derrida.

This repository only holds the playable game; it is published from a private source repository.

This is an unofficial fan project, not affiliated with or endorsed by the rights holders. All rooms, models, sound and text are new; no original game data is included. Third-party: [three.js](https://threejs.org) (MIT, `vendor/three-LICENSE`), [VT323](https://fonts.google.com/specimen/VT323) font (SIL OFL, `fonts/OFL.txt`).
